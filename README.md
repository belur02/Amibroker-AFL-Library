# Amibroker Formula Language (AFL) Collection

This repository contains a comprehensive collection of Amibroker Formula Language (AFL) scripts, organized by category. These scripts can be used for technical analysis, system development, scanning, and charting within the Amibroker software.

## Directory Structure

The repository is organized into the following directories:

*   **`Indicators/`**: Contains a wide range of standard and custom technical indicators (e.g., RSI, MACD, ADX, Bollinger Bands, etc.).
*   **`Systems/`**: Includes complete trading systems, strategies, and signal generation scripts.
*   **`Explorationn/`**: Scripts designed specifically for Amibroker's "Exploration" feature, allowing you to scan the market for specific conditions.
*   **`Basic Charts/`**: Basic chart templates and modifications, such as Price, Volume, and Ichimoku charts.
*   **`Report Charts/`**: Scripts for generating reports and visualizing portfolio equity, such as "Portfolio Equity" and "Profit Table".
*   **`Custom/`**: A collection of miscellaneous custom scripts, experiments, and specialized indicators.
*   **`Averages/`**: Various implementations of moving averages (SMA, EMA, WMA, etc.).
*   **`Bands/`**: Band-based indicators like Bollinger Bands and Keltner Bands.

## Usage

To use these scripts in Amibroker:

1.  Download the `.afl` file(s) you wish to use.
2.  Copy the file(s) to your Amibroker `Formulas` directory. This is typically located at:
    *   `C:\Program Files\Amibroker\Formulas\` (or your specific installation path).
    *   You can organize them into subfolders within the `Formulas` directory to match the structure of this repository.
3.  Open Amibroker.
4.  Go to the **Charts** window/pane.
5.  Navigate to the folder where you saved the scripts.
6.  Drag and drop the formula onto a chart, or right-click and select "Insert" or "Overlay".
